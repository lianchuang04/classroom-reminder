# 📚 智能课表提醒系统 (Smart Course Schedule Reminder)

> 一个基于 GitHub Actions + Node.js 的全自动课表推送系统，每天定时通过微信推送当日课程安排。
>
> 🏗 土木工程专业 × 🤖 AI 自动化 — 用技术解决真实生活问题

---

## 🎯 项目背景

大学课程安排复杂，许多课程并非每周都上（如"工程经济与管理"仅在第9-16周开设），传统纸质课表需要手动核对周次，容易搞错。本系统自动计算当前教学周，**只显示当周有效的课程**，并通过微信每天早晨推送，彻底解决"忘了今天有什么课"的问题。

## ✨ 核心功能

- **智能周次过滤** — 自动计算当前是第几教学周，只显示当周实际开设的课程
- **多时段感知** — 区分上午/下午/晚上时段，按时间排序展示
- **下一节课提醒** — 自动判断当前时间之后的第一节课
- **微信推送** — 通过 Server酱 每天 7:00 准时推送到微信
- **全自动运行** — 基于 GitHub Actions 定时触发，无需本地部署

## 🛠 技术栈

| 技术 | 用途 |
|------|------|
| **Node.js** | 主程序开发，课程数据建模与消息生成 |
| **GitHub Actions** | CI/CD 定时任务调度（Cron 表达式） |
| **Server酱 API** | 微信消息推送通道 |
| **PDF.js** | 课表 PDF 解析与结构化数据提取 |
| **Semver & Git** | 版本管理与项目迭代 |

### 核心逻辑流

1. **数据建模** — 将课表按课程名称、时间段、教学周次、地点、教师建立结构化数据模型
2. **时间感知** — 根据学期起始日期自动计算当前教学周，结合课表周次范围做条件过滤
3. **消息编排** — 按星期+时间段排序，自动判断下一节课，生成人性化提醒文案
4. **自动化部署** — GitHub Actions Cron 定时触发，全自动无人值守运行

## 🚀 快速开始

### 本地运行

```bash
npm install
SERVER_CHAN_KEY=your_key_here node src/index.js
```

### GitHub Actions 部署

1. 将本项目 Fork 或推送到你的 GitHub 仓库
2. 在 Settings → Secrets and variables → Actions 中配置：
   - `SERVER_CHAN_KEY`：你的 Server酱 SendKey
3. 每天 7:00 自动推送，也可在 Actions 页面手动触发

## 🔧 技术亮点

1. **PDF 课表自动解析** — 使用 PDF.js 配合中文字体映射（CMap）从学校导出的课表 PDF 中提取结构化数据
2. **周次感知引擎** — 基于学期起始日期自动计算当前教学周，精确到第几周
3. **条件化推送** — 周五至周日无课自动跳过，不浪费推送配额
4. **GitHub Actions Cron** — 利用 CI/CD 平台实现定时任务，零成本运维
5. **微信消息推送** — 通过 Server酱 API 实现消息推送，无需自建服务器
